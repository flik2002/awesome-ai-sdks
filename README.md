# Awesome AI SDKs

A curated list of SDKs, frameworks, and tools for building AI agents.

## Submitting PRs

We welcome contributions! If you have an SDK, framework, or tool that should be added to this list, please submit a pull request.

When submitting a PR, please ensure:
- The SDK/tool is related to AI agents
- The entry follows the existing format
- The description is concise and informative
- Links to official website and/or GitHub repository are included

## Adding Your Project

1. Fork this repository
2. Create a new branch for your addition
3. Add your SDK in alphabetical order
4. Submit a pull request with a brief description

## SDKs

### AgentOps
[AgentOps](https://www.agentops.ai/) - Monitoring and debugging platform for AI agents.

### Chronology
[Chronology](https://chronology.dev/) - A framework for building AI agents with memory and persistence.

### Helicone
[Helicone](https://www.helicone.ai/) - Open-source observability platform for LLM applications.

### LangChain
[LangChain](https://www.langchain.com/) - Framework for developing applications powered by language models.

### Langfuse
[Langfuse](https://langfuse.com/) - Open-source analytics and tracing for LLM applications.

### OpenClaw Monitor
[OpenClaw Monitor](https://github.com/monitor-lab/openclaw-monitor) - Local monitoring dashboard for OpenClaw AI agents. Go backend with React UI that visualizes health, sessions, logs, and agent events.

### SID
[SID](https://www.sid.ai/) - AI agent development platform with integrated development environment.

### Vercel AI SDK
[Vercel AI SDK](https://sdk.vercel.ai/) - Type-safe framework for building AI-powered applications.
